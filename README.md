# Nikhil Tembhe — Developer Portfolio

A responsive, single-page developer portfolio styled to closely follow the supplied Aditi Arya reference video. The opening screen uses the same compact navigation, centered monospaced hero, teal/purple atmospheric background, rose typewriter tagline, small social icons, scroll cue, and slim right-edge scroll marker. The portfolio wording and sections are adapted to Nikhil's resume.

## Files

- `index.html` — page structure and portfolio content
- `assets/css/style.css` — theme, responsive layout and visual styling
- `assets/js/main.js` — typewriter animation, mobile navigation, scroll marker and section reveal behavior
- `assets/resume.pdf` — resume linked from the page

## Run locally

Open `index.html` in a browser. No build step or package installation is required. The Google Font is loaded from Google Fonts when an internet connection is available; a system monospace fallback is included.

## Publish on `nikhilt.tech`

Upload the contents of this folder to a static host such as Netlify or GitHub Pages, then connect the domain using the hosting provider's DNS instructions. Keep `index.html` at the published site's root.

- Confirm that the resume's employment dates and wording are current.
